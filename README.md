# Biological Data Formats

**Biological Data Formats** — учебный проект на Python для чтения и анализа биологических данных в форматах **FASTA, FASTQ, SAM и VCF**.

Проект разработан в рамках дисциплины «Информатика» и демонстрирует применение объектно-ориентированного программирования: абстрактных классов, наследования, полиморфизма и генераторов.

## Возможности программы

### FASTA — `FastaReader`

- Чтение FASTA-файлов, включая многострочные последовательности.
- Получение идентификаторов последовательностей.
- Подсчёт количества последовательностей.
- Вычисление средней длины.
- Базовая проверка последовательностей.

### FASTQ — `FastqReader`

- Чтение ридов и строк качества.
- Получение идентификаторов последовательностей.
- Подсчёт количества и средней длины ридов.
- Проверка допустимых нуклеотидов.
- Построение трёх графиков:
  - распределение длин последовательностей;
  - показатели качества Phred по позициям;
  - нуклеотидный состав по позициям.

Графики сохраняются в `fastq_report.png`.

При построении графиков некорректные записи с различающимися длинами последовательности и строки качества пропускаются с предупреждением.

### SAM — `SamReader`

- Чтение выравниваний с помощью генератора.
- Извлечение идентификаторов ридов, хромосом и координат.
- Получение информации из поля `CIGAR`.
- Обработка заголовков `@PG` и `@RG`.
- Получение списка хромосом.
- Статистика количества выравниваний по хромосомам с помощью `pandas`.
- Поиск выравниваний по заданному региону.

**Ограничение:** в текущей версии поиск пересечений учитывает начальную координату `POS`, а не всю длину выравнивания по `CIGAR`.

### VCF — `VcfReader`

- Чтение генетических вариантов через `yield`.
- Получение заголовков и метаданных.
- Проверка обязательных полей VCF.
- Подсчёт количества вариантов.
- Получение списка хромосом.
- Определение референсного генома.
- Расчёт статистики по геномным регионам через `pandas`.
- Поиск вариантов, пересекающих заданный интервал, с учётом длины `REF` и поля `INFO/END`.

## Архитектура проекта

Программа построена с использованием абстрактного класса `Reader` и двух специализированных базовых классов.

```text
Reader
├── SequenceReader
│   ├── FastaReader
│   └── FastqReader
└── GenomicDataReader
    ├── SamReader
    └── VcfReader
```

`SequenceReader` предназначен для FASTA и FASTQ, а `GenomicDataReader` — для SAM и VCF.

Использование генераторов позволяет последовательно обрабатывать записи биологических файлов.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/polinakuklina07-max/biological-data-formats.git
cd biological-data-formats
```

Установите зависимости:

```bash
python3 -m pip install pandas matplotlib seaborn sphinx
```

## Запуск

Из корня репозитория выполните:

```bash
python3 demo.py
```

Демонстрационная программа последовательно запускает обработку FASTA, FASTQ, SAM и VCF.

Для выполнения без графического интерфейса:

```bash
MPLBACKEND=Agg python3 demo.py
```

После запуска в корне проекта создаётся файл `fastq_report.png`.


## Тестовые данные и результаты

В каталоге `test_data` представлены образцы каждого поддерживаемого формата.

При демонстрации VCF на файле `vcf_practice_extended.vcf` получены следующие результаты:

| Параметр | Результат |
|---|---|
| Количество вариантов | 24 |
| Хромосомы | `chr1`, `chr2`, `chr7`, `chrX` |
| Референсный геном | `synthetic_GRCh38_like` |
| Пересечения с `chr7:350000–350050` | 1 вариант |

В частности, поиск пересечений обнаруживает структурный вариант, начинающийся до исследуемого интервала, но пересекающий его по конечной координате `END`.

Тестовые данные используются для демонстрации функциональности парсеров.
