# Biological Data Formats

## Описание проекта

**Biological Data Formats** — учебный проект на Python для чтения и анализа биологических данных в форматах FASTA, FASTQ, SAM и VCF.

Проект разработан в рамках дисциплины «Информатика» и демонстрирует применение принципов объектно-ориентированного программирования (ООП): абстрактных классов, наследования, полиморфизма и генераторов.

Для обработки и анализа данных используются стандартные средства Python, а также библиотеки `pandas`, `matplotlib` и `seaborn`.

## Возможности программы

### FASTA — `FastaReader`

Класс предназначен для чтения файлов, содержащих нуклеотидные и белковые последовательности.

Реализованные возможности:

- Чтение FASTA-файлов с помощью генератора `yield`.
- Обработка многострочных последовательностей.
- Получение идентификаторов последовательностей.
- Подсчёт количества последовательностей.
- Вычисление средней длины последовательностей.
- Базовая проверка последовательности на непустое содержимое.

### FASTQ — `FastqReader`

Класс предназначен для обработки результатов секвенирования, включающих нуклеотидные последовательности и показатели качества.

Реализованные возможности:

- Чтение записей FASTQ.
- Получение идентификаторов ридов.
- Подсчёт количества последовательностей.
- Вычисление средней длины ридов.
- Проверка допустимых нуклеотидных символов.
- Построение графиков качества и состава последовательностей.

Программа строит три графика:

1. **Sequence Length Distribution** — распределение длин последовательностей.
2. **Per Base Sequence Quality** — показатели качества Phred по позициям.
3. **Per Base Sequence Content** — процентное содержание нуклеотидов A, T, G и C по позициям.

Результаты визуализации сохраняются в файл `fastq_report.png`.

При построении графиков записи с несовпадающими длинами последовательности и строки качества пропускаются с предупреждением. Проверка всех возможных ошибок структуры FASTQ пока не реализована.

### SAM — `SamReader`

Класс предназначен для чтения и анализа выравниваний последовательностей.

Реализованные возможности:

- Чтение SAM-файла с помощью генератора.
- Получение идентификаторов ридов.
- Получение названий хромосом и начальных координат выравниваний.
- Извлечение поля `CIGAR`.
- Обработка заголовков `@PG` и `@RG`.
- Получение списка хромосом.
- Подсчёт выравниваний по хромосомам с использованием `pandas`.
- Поиск выравниваний, начальные позиции которых находятся внутри заданного региона.

**Ограничение:** текущий поиск пересечений SAM учитывает только начальную координату `POS`. Полное определение пересечения по длине выравнивания, рассчитанной из `CIGAR`, требует доработки.

### VCF — `VcfReader`

Класс предназначен для чтения и анализа генетических вариантов.

Реализованные возможности:

- Чтение VCF-файлов с помощью генератора `yield`.
- Получение заголовков и метаданных.
- Проверка обязательных столбцов VCF.
- Подсчёт количества вариантов.
- Получение списка хромосом.
- Определение референсного генома из заголовка.
- Проверка геномных координат.
- Расчёт статистики вариантов по геномным регионам с использованием `pandas`.
- Поиск вариантов, пересекающих заданный интервал, с учётом длины `REF` и параметра `END` из поля `INFO`.

## Архитектура проекта

Проект построен на системе абстрактных классов.

`Reader` — основной абстрактный класс, определяющий общий интерфейс чтения и анализа файлов.

От него наследуются:

- `SequenceReader` — базовый класс для последовательностей FASTA и FASTQ.
- `GenomicDataReader` — базовый класс для геномных форматов SAM и VCF.

Структура наследования:

```text
Reader
├── SequenceReader
│   ├── FastaReader
│   └── FastqReader
└── GenomicDataReader
    ├── SamReader
    └── VcfReader
```

Применение генераторов позволяет обрабатывать записи последовательно, без необходимости хранить все записи файла в памяти одновременно.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/polinakuklina07-max/biological-data-formats.git
cd biological-data-formats
```

### 2. Установка зависимостей

```bash
python3 -m pip install pandas matplotlib seaborn sphinx
```

## Запуск программы

Для запуска общей демонстрации выполните команду из корня репозитория:

```bash
python3 demo.py
```

Программа последовательно запускает обработку четырёх форматов:

```python
run_fasta_demo()
run_fastq_demo()
run_sam_demo()
run_vcf_demo()
```

При выполнении в среде без графического интерфейса:

```bash
MPLBACKEND=Agg python3 demo.py
```

После запуска формируется изображение `fastq_report.png` с графиками FASTQ.



## Тестовые данные и результаты

Для проверки работы парсеров в проект включена папка `test_data`.

Она содержит тестовые файлы форматов FASTA, FASTQ, SAM и VCF.

При демонстрации на расширенном тестовом файле `vcf_practice_extended.vcf` получены результаты:

| Параметр | Значение |
|---|---|
| Количество вариантов | 24 |
| Хромосомы | `chr1`, `chr2`, `chr7`, `chrX` |
| Референсный геном | `synthetic_GRCh38_like` |
| Пересечения с `chr7:350000–350050` | 1 вариант |

Поиск пересечений обнаруживает в том числе структурные варианты, начальная позиция которых находится вне запрошенного региона, но конечная координата `END` попадает в него.

Файлы являются учебными данными и предназначены для проверки работы программы.

## Командная разработка

Проект создаётся совместно с использованием Git и GitHub.

В ходе разработки использовались рабочие ветки:

- `feature/fastq`
- `feature/sam`
- `feature/vcf`

Основная ветка с объединённым кодом — `main`.

Каждый участник отвечает за реализацию отдельного формата. Работа участников интегрируется в общую программу `demo.py`.
