# Analysis-FASTQ-with-a-graphical-interface

Реализация графического интерфейса (GUI) для модуля чтения и анализа биологических файлов формата FASTQ.

## Возможности
- **Выбор файлов** через системный диалог с фильтром по форматам (`.fastq`, `.fq`, `.fastq.gz`, `.fq.gz`).
- **Статистический анализ** файла в один проход:
  - Количество ридов.
  - Средняя, минимальная и максимальная длина последовательностей.
  - Среднее качество.
  - GC-состав.
- **Визуализация графиков** (встроенных прямо в окно приложения с возможностью масштабирования и сохранения):
  - Распределение длин последовательностей.
  - Качество по позициям (Boxplot).
  - Состав нуклеотидов по позициям (A, T, G, C).
- **Вывод предупреждений** о некорректных записях (битые данные, неверный ASCII-символ качества).
- Работа с большими файлами не подвешивает интерфейс (анализ выполняется в фоновом потоке).

## Установка и запуск

### 1. Требования
- Python 3.9 или выше.
- Установленный пакет `tkinter`.

### Установка и запуск (Linux)

    Клонируйте репозиторий:

    git clone https://github.com/SonyaShust/Analysis-FASTQ-with-a-graphical-interface.git
    python -m fastqc_gui.run
