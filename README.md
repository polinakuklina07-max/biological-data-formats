# Biological Data Formats

## Описание проекта

**Biological Data Formats** — учебный проект по информатике, посвящённый объектно-ориентированному программированию на Python и обработке биологических данных.

Программа позволяет читать и анализировать файлы четырёх биоинформатических форматов: FASTA, FASTQ, SAM и VCF.

Для реализации используются наследование классов, абстрактные методы, генераторы `yield`, а также библиотеки `pandas`, `matplotlib` и `seaborn`.

## Возможности программы

### FASTA — FastaReader

- Чтение последовательностей в формате FASTA.
- Получение идентификаторов последовательностей.
- Подсчёт количества последовательностей.
- Вычисление средней длины последовательностей.
- Базовая проверка последовательностей.

### FASTQ — FastqReader

- Чтение последовательностей и значений качества FASTQ.
- Подсчёт количества ридов.
- Вычисление средней длины ридов.
- Проверка допустимых нуклеотидов.
- Построение трёх графиков:
  - распределение длин последовательностей;
  - качество по позициям (Phred);
  - нуклеотидный состав по позициям.

Графики сохраняются в файл `fastq_report.png`.

При построении графиков записи с несовпадающими длинами последовательности и строки качества пропускаются с предупреждением.

### SAM — SamReader

- Чтение выравниваний из SAM-файла.
- Получение идентификаторов ридов, хромосом, начальных позиций и CIGAR.
- Обработка заголовков `@PG` и `@RG`.
- Подсчёт выравниваний по хромосомам с помощью `pandas`.
- Поиск выравниваний, начальная координата которых попадает в заданный регион.

**Примечание:** поиск пересечений SAM пока не учитывает всю длину выравнивания по CIGAR.

### VCF — VcfReader

- Чтение генетических вариантов из VCF.
- Обработка метаданных и заголовков.
- Подсчёт количества вариантов.
- Получение списка хромосом.
- Определение референсного генома из заголовков.
- Подсчёт вариантов по геномным регионам с использованием `pandas`.
- Поиск вариантов, пересекающих заданный интервал, с учётом длины REF и поля INFO/END.

## Архитектура проекта

В основе программы лежит абстрактный класс `Reader`, от которого наследуются два класса:

- `SequenceReader` — базовый класс для FASTA и FASTQ.
- `GenomicDataReader` — базовый класс для SAM и VCF.

Структура наследования:

```text
Reader
├── SequenceReader
│   ├── FastaReader
│   └── FastqReader
└── GenomicDataReader
    ├── SamReader
    └── VcfReader
```

## Установка и запуск

**1. Клонировать репозиторий**

```bash
git clone https://github.com/polinakuklina07-max/biological-data-formats.git
cd biological-data-formats
```

**2. Установить библиотеки**

```bash
python3 -m pip install pandas matplotlib seaborn
```

**3. Запустить демонстрацию**

```bash
python3 demo.py
```

При запуске в среде без графического интерфейса:

```bash
MPLBACKEND=Agg python3 demo.py
```

После запуска программа последовательно демонстрирует работу FASTA, FASTQ, SAM и VCF.

## Тестовые данные и пример результатов

В папке `test_data` находятся образцы файлов каждого формата.

При проверке расширенного файла `vcf_practice_extended.vcf` получены следующие результаты:

- Количество вариантов: **24**.
- Хромосомы: `chr1`, `chr2`, `chr7`, `chrX`.
- Референсный геном: `synthetic_GRCh38_like`.
- Для региона `chr7:350000–350050` найден один пересекающий вариант.

Для FASTQ программа создаёт изображение с тремя графиками качества и состава последовательностей.

## Демонстрация работы

Основной файл для демонстрации — `demo.py`.

Он последовательно запускает:

```python
run_fasta_demo()
run_fastq_demo()
run_sam_demo()
run_vcf_demo()
```

Каждый парсер также можно импортировать отдельно для использования в других Python-программах.
