Параметры:

save_path (str, optional) – Путь для сохранения картинки. Если None, график выводится на экран.

dict – Словарь с ключами „header“, „sequence“ и „quality“.

Переопределяем метод из базового класса. Проверяет, что последовательность состоит только из символов A, T, G, C, N.
