
Biological Data Formats
=======================

Документация учебного проекта по обработке
биологических данных с использованием Python
и объектно-ориентированного программирования.

Поддерживаемые форматы:

* FASTA
* FASTQ
* SAM
* VCF

Архитектура
-----------

В основе программы лежит абстрактный класс Reader.

От него наследуются:

* SequenceReader — работа с последовательностями.
* GenomicDataReader — работа с геномными данными.

Конкретные реализации:

* FastaReader
* FastqReader
* SamReader
* VcfReader
